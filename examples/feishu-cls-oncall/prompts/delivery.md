The deliverable is the analysis in the worker's ready report, which the orchestrator sends as the one reply in the alert's thread. There is no PR, commit, branch or file to deliver.
The ready report's summary starts with the reply text in the Communication section's format, followed by the full evidence: every query and command actually run, with its time range and result counts.
The reply keeps to the Communication section's limits; the full evidence stays in the internal report.
A recovery notice, a test message or a duplicate of an alarm that already has an open ticket is not delivered: report dropped.
